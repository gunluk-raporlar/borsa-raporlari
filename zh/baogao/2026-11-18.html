2. 市场解读与传导机制

截至2026年11月18日07:24——BIST 30（XU030）最新收盘14.614.92；前收盘14.841.53（日跌幅-1.53%）；以美元计价的日表现-1.55%。XU100也以相同幅度下跌-1.53%，降至11.661.00点；而USD/TRY为50.43，较前收盘仅上涨+0.02%。这一图景表明，抛售压力并非源于汇率，而是由内部动态驱动：里拉回报与美元计价回报之间仅0.02个百分点的差距，证实了在汇率保持中性的这一天，下跌直接来自股价。

传导链条如下运作：广泛的抛售转化为指数权重板块的同步走弱。银行和控股板块由强力卖出主导（SAHOL, SISE, PETKM 组合中20/0-1的卖出票数），工业板块ADX处于15-16区间的疲弱趋势，暗示下跌并非局限于单一行业，而是风险减仓性质，而非板块轮动。相反，航空板块作为分化的唯一一极脱颖而出：TAVHL 在指数下跌时以-0.41%保持抗跌，而PGSUS +% 以0.83成为当日唯一上涨的股票；THYAO' 的ADX 38.25确认了强劲趋势，但RSI 71.29使超买警告保持活跃。

板块效应对个股的反映勾勒出双向风险地图。上行方面，航空板块通道位置处于104-109%区间（超买区域）以及THYAO 和 PGSUS' 的RSI高于70，表明当前动能可能因获利了结而受到考验；GARAN' 尽管中期/长期为买入信号，但WT=卖出在短期内提示谨慎，BIMAS' 的CCI 135.88则显示防御性替代品保持强劲姿态。下行方面，ISCTR' 的强力卖出与WT=卖出组合，以及GUBRF' 的ADX达到52.61的强劲下跌趋势，表明在卖出票数集中的组合中，下行情景尚未耗尽。在此框架下，指数若在14.614.92下方站稳，则凸显减少强力卖出组合中的权重；航空板块则凸显在超买区域逐步获利了结的纪律。

3. 宏观展望与新闻动态

11月通胀数据月率为2.58%，高于2.4%的预期，年率为29.77%，略高于前值29.73%；核心通胀降至28.3%则勾勒出矛盾的图景。政策利率已在10月从37%下调至36%，实际利率约为+4.80%，仍处于正值区域。这一位置缩小了TCMB的降息空间但并未完全关闭；存款利率从42.04%降至42,752%，信贷增长年率从36.32%降至35.29%，表明货币传导正在发挥作用，但冷却内需的速度在放缓。消费者信心从91.9急剧下降至84.8点，经济预期指数从101.3降至97.3，表明家庭部门的支出意愿减弱；这被零售销售月增幅从1.4%降至0.1%所证实。BIST 30下跌1.53%至14.614.92点，以美元计价也以-1.55%几乎相同幅度下跌，表明抛售并非源于汇率，而是来自内部动态；USD/TRY在50,437横盘整理时，这种分化更加明显。

银行板块方面，利率螺旋直接转化为利润率压力。 尽管政策利率下调，存款成本仍坚挺在42%水平，意味着贷存利差收窄；信贷增长放缓也限制了规模方面的净利息收入。GARAN' 的中长期信号仍处于买入区域，表明市场并非未对这一利润率压缩定价，而是尚未看到资产负债表确认；ISCTR' 的强力卖出与WT=卖出组合则暗示风险在银行内部出现分化，即并非全行业抛售，而是选择性逃离。若季度净息差数据出现改善，这一观点将失效；否则存款利率的高企将继续对银行盈利能力构成下行压力。

工业和出口方面，汇率的横盘走势双向发挥作用。 USD/TRY在50,437几乎保持不变，未对进口投入成本造成额外冲击；但也没有为出口收入提供汇率支撑。工业生产月增2.1%，从前值-1.0%回升，产能利用率升至74.5%，表明生产端出现复苏；然而制造业PMI从55.6降至54.6点，商业信心从102.0降至99.8，是对这一复苏失去动能的早期警告。GUBRF' 的ADX 52.61显示强劲下跌趋势，60日回报-41.9%的深度负值表明，即使在工业内部，分化也在加剧，投资者不会宽恕疲弱的资产负债表。汇率保持横盘不会改变这一图景；但如果里拉出现快速贬值，出口商利润率将得到支撑，而依赖进口投入的个股则成本压力将重新浮现。

航空业作为受宏观螺旋影响最小的行业而脱颖而出。 伊斯坦布尔机场的旅客数量和增长位居欧洲之巅，旅游收入增至季度255.3亿美元，游客数量以年率0.4%转正，这些支撑了该行业的运营叙事；Pegasus（佩加苏斯）' 其净利润超出预期也为这一图景画上句号。TAVHL' 在指数下跌时仅回落-0.41%，以及振荡指标中给出强力买入（17/3）信号，PGSUS' 其以+0.83%成为当日唯一收涨，表明投资者在逃离通胀-利率螺旋时将航空业视为避风港。然而THYAO' RSI为71.29，以及PGSUS' 通道109%的过热区域警告提醒人们，这种强势短期内易受获利回吐影响；JPMorgan上调土耳其股票建议对资金流入构成支撑，但单凭此并不足以决定方向。

新闻流由三个限制风险偏好的标题塑造。 Adil Katılım Bankası管理层被移交至TMSF以及基金调查中21家公司被任命受托人，作为损害金融体系信任感的事态发展而突出；此类标题并不直接针对BIST 30公司，但推高了银行股的风险溢价。对外国投资者以15万美元下限提供5年居留许可的规定，以及为中小企业绿色转型提供30亿里拉支持计划，中期内对资本流入和工业转型构成积极因素；但其影响尚未反映在今日定价中。全国住房销售下降36%，高信贷利率（消费信贷66.46%）证实了建筑和耐用消费品相关标的的需求疲软。VIX从22.91跃升至25.46，涨幅11.13%，表明全球风险偏好恶化，在此环境下由内部动态驱动的抛售更易蔓延；BIMAS 等防御性标的维持长期买入信号，是这种逃逸流向何处的具体迹象。

从资产负债表规模看，流动资产基础最雄厚的公司为Koç Holding（科奇控股公司） ( 4,038.74 十亿 TL），Sabancı Holding（公司） ( 2,929.87 十亿 TL）和土耳其航空公司 ( 559.18 十亿 TL）脱颖而出；这三者代表了指数总流动性资源能力的重要部分。相比之下，土耳其黄金企业 ( 23.60 十亿 TL）、Türk Metal（23.84 十亿 TL）和Kardemir (卡尔德米尔) ( 33.84 十亿 TL）在流动资产基础上构成最有限的群体。流动资产规模本身并非盈利指标；但从偿付短期负债的灵活性和营运资金操作空间看，可解读为控股公司与航空板块相对宽裕，而矿业和钢铁板块基础较窄。

在 Havacılık（航空）方面 土耳其航空公司' 的 559.18 十亿 TL 和Pegasus（佩加苏斯）' 的 122.08 十亿 TL 流动资产，结合该板块在 60 日回报中的正向分化来看，表明运营现金生成已反映到资产负债表；TAV机场' 的 72.63 十亿 TL 水平则对应与基础设施为主商业模式相符的、相对较小但稳定的流动性基础。银行和控股板块方面，Garanti BBVA（银行） 和 İş Bankası（伊什·班卡瑟）' 的资产负债表结构在本数据集中未被拆分，但板块整体 GÜÇLÜ SAT 信号占主导，表明技术性定价压力比盈利能力和资本充足率比率更为突出。防御性方面，BİM 的 171.99 十亿 TL 流动资产，结合零售商业模式的现金周期，在指数下跌中凸显为支撑其替代性定位的因素。

回报方面，资产负债表规模与价格表现之间的分化引人注目：60 日回报中航空股保持在 6%-10 区间的正值，而土耳其黄金企业' 为 32.1%，Gübre Fabrikaları (居布雷·法布里卡拉勒)' 为 41.9%，Astor Enerji (阿斯托尔能源)' 为 52.6% 的深度负回报。这一图景暗示流动资产规模本身并不足够，市场对盈利可持续性和现金生成质量赋予了更大权重。在基于比率的评估中，由于数据集仅包含流动资产项目，负债率、净利润率和净资产收益率等比率在本节无法衡量；因此，公司层面的盈利判断应在现有数据的局限内谨慎对待，要得出关于资产负债表质量的最终结论还需额外的财务报表数据。

6. 风险管理与情景

在下行情景中，触发因素是卖出票数集中在20/0-1水平的强力卖出集群：SAHOL ( al=0/sat=20），SISE ( al=1/sat=20），AEFES, SASA 和 PETKM' 中（al=1/sat=18-19），振荡指标几乎全部指向卖出方向。在这些标的中，ADX在25-30区间运行，而GUBRF' 中ADX为52.61，显示出强劲的下跌趋势；若指数在14,614.92收盘价下方站稳，则该集群中可能出现新的探底以及抛售压力向银行业蔓延（ISCTR 总体=强力卖出，WT=卖出）是主要风险因素。而上行情景则取决于航空板块能否维持抗跌走势：TAVHL 总体=买入且振荡指标为强力买入（17/3），日跌幅为-0.41%，损失有限，而PGSUS +% 以0.83成为唯一正向分化的标的；THYAO' 中ADX 38.25确认了强劲趋势，但RSI 71.29处于超买区域。这三者的通道位置在88%-109区间，即接近上轨；因此即使在上行情景中，也应保持逐步获利了结的纪律，RSI高于70的THYAO 和 PGSUS' 中，应优先持有现有仓位而非新建买入。

作为组合保护盾，防御性方面BIMAS 表现突出：长周期买入、振荡指标买入（16/8）以及CCI 135.88，对指数下跌起到平衡作用；GARAN' 中中/长周期买入和振荡指标买入（14/5）信号得以维持，而WT=卖出要求短期保持谨慎。应对下行情景最有效的保护是减少强力卖出集群中的权重，并将释放出的份额转入现金/流动性缓冲；该缓冲应与模型组合的现金行保持一致，在保持航空板块权重的同时逐步降低总体风险偏好。汇率方面，USD/TRY为50.43，+0.02%横盘运行，表明下跌并非源于汇率，而是由内部动态驱动；因此保护盾的重点应放在选股和仓位规模管理上，而非汇率对冲。

情景的失效条件应明确：航空板块中RSI高于70的水平（THYAO 71.29; PGSUS 70.62）通过获利回吐回归正常，以及TAVHL' 中通道位置从88%向下松动，将削弱上行情景；相反，强力卖出集群中卖出票数减少以及BIMAS/GARAN' 中振荡指标支撑持续，则可阻止下行情景加深。即使指数站稳14,614.92上方，对于GUBRF ( ADX 52.61）和PETKM ( CCI20 -87.62）等趋势疲弱的标的，也应等待确认后再加仓；反之则应扩大现金缓冲，优先保护资本。

方法论与术语

  • 信号（总体）： 基于个股的总体技术评估（强力买入 / 买入 / 中性 / 卖出 / 强力卖出）；在面板和技术扫描表中可见。
  • 振荡器投票： RSI、StochK、MACD、CCI、WT 等指标的个别买入/卖出票数；以"11 买入/8 卖出"形式给出，并可能与整体信号相矛盾（例如面板信号为卖出时，振荡器票数中某只个股可能出现正向背离）。
  • WT（波浪趋势）： 短期周期（顶/底）振荡器；产生买入/卖出票数。
  • 通道（%N）： 价格在 60 日回归通道中的位置；0% 接近通道下沿（底部区域），100% 接近通道上沿（顶部区域）。
  • ADX: 平均方向指数（ADX）；数值高于 25 显示强趋势，低于 20 显示弱/横盘走势。
  • r: 在 60 日窗口中计算的皮尔逊相关系数（趋势强度指标）；在模型投资组合表中以括号形式给出。
  • 现金： 模型投资组合中未分配给个股、为保持流动性而保留的比例。
