1. 市场摘要与概览

27 Ekim 2026 Salı günü, saat 12:22 itibarıyla BIST 30 (XU030) 指数在13,972.47水平，较前一收盘上涨0.17%；BIST 100 (XU100) 指数则在11,181.86水平，获利0.27%，而USD/TRY汇率在49.71水平显示0.06%回落。以美元计价的XU030表现因汇率修正提供了0.23%正向差异。Brent石油价格从110.34 USD/varil水平回落5.47%跌至110美元以下，VIX指数下跌5.40%至18.4水平，表明风险偏好相对增加。投资组合层面，测试组合自2026-09-06以来回报%-15.18，低于XU030 (-16.63%)、XU100 (-11.20%)、Döviz (+21.67%)、Altın (+10.41%)和Vadeli Mevduat (+25.54%)所有比较基准。宏观层面，Türkiye'nin Eylül 2026年度消费者通胀为29.73%，政策利经22 Ekim 2026决定维持在36.0%。ABD方面核心通胀2.6%，政策利率4.0%，DXY指数在102.02区间波动。

全球风险感知与石油动态

Brent石油从116.72 USD/varil回落至110.34 USD/varil，强化了能源成本推动的通胀压力可能减轻的预期。然而，WTI下跌1.74%维持在101.47 USD/varil，显示全球需求担忧持续。ABD 10年期国债收益率在4.82%区间徘徊且曲线趋平，反映Fed降息预期推迟。Euro Bölgesi核心通胀维持在2.5%，ECB政策利率维持在2.65%，显示Avrupa Merkez Bankası的谨慎立场。

本地流动性与银行业板块压力

根据 TCMB 数据，截至 2026 年 8 月，年信贷增长为 36.32%，M3 货币供应增长为 28.65%，而实际利率仍处于负值区域，助长了对银行股的卖压。BIST 30 中的五大银行（AKBNK, GARAN, ISCTR, VAKBN, YKBNK) 在技术扫描和振荡指标数据中完全给出"强烈卖出"信号，成为阻碍指数优异表现的主要推动力量。 Vakıfbank（银行） 和 Yapı Kredi（银行）' Wave Trend 处于"卖出"而其余处于"强烈卖出"位置，回归通道位置（通道 % 在 -6 至 27% 区间）确认价格低于均值。

2. 分板块评估

银行业：结构性抛售压力持续

银行指数成分在技术和振荡器数据中无一例外显示疲弱局面。Akbank 阿克银行 ( RSI 38.01, ADX 34.20), Garanti BBVA（银行） ( RSI 44.08, ADX 20.85), İş Bankası（伊什·班卡瑟） ( RSI 38.59, ADX 20.17), Vakıfbank（银行） ( RSI 33.77, ADX 22.54) 和 Yapı Kredi（银行） ( RSI 46.50、ADX 17.87）这些股票因 MACD 保持在负值区域以及 CCI20 指标处于 -50 至 -190 之间的深度超卖区域而引人注意。皮尔逊相关系数（r）在 -0.04 至 -0.35 之间波动，回归通道位置显示价格在其趋势通道的下沿或非常接近下沿处交易。信贷增长的放缓和净息差压力继续削弱该行业的基本面动态。

能源与石化：Tüpraş (图普拉什) 分化，其余疲弱

Tüpraş（公司） ( TUPRS）以 27.70% 的 60 日回报提供行业内唯一的正向分化，并给出 Wave Trend"买入"和长期 EMA"买入"。但以短期和中期 EMA"持有"、总体评分"中性"以及 TradingView 建议"卖出"（买入=7/卖出=12）绘制出混合图景。 Petkim (佩特基姆) ( PETKM), Enka İnşaat (恩卡建筑) ( ENKAI）以及 Astor Enerji (阿斯托尔能源) ( ASTOR）股票分别以 -9.5%、-11.6%、-42.4% 的 60 日回报处于深度调整中。Astor Enerji (阿斯托尔能源)' 日内 9.95% 的反弹运动依托通道 67% 水平（超买区域）发生，尽管 Wave Trend 给出"底部买入"信号，总体趋势仍处于"卖出"。

汽车与国防：消息流与技术结构对比

Tofaş（公司） ( TOASO）和 Ford Otosan（公司） ( FROTO）股票虽以日涨 2.14% 和 2.35% 脱颖而出，但 60 日表现分别为 -17.8% 和 -13.7%，仍处负值区。汽车行业 300 百万美元投资的消息（CNN Türk）可能对市场情绪产生积极影响，但在技术结构中，两只股票均显示 EMA 排列“卖出/观望”、Wave Trend“底部买入”，以及 -0.50 和 -0.79 的 Pearson 相关性所体现的强负相关。Aselsan（公司） ( ASELS）、SSB 以 5.23 亿欧元合同消息（BloombergHT、CNN Türk (CNN 图尔克)、Sabah Ekonomi）支撑基本面，但技术扫描给出“整体=卖出”（短期=持有，中期=卖出，长期=持有），Wave Trend“买入”。振荡器中 RSI 44.05、MACD -8.87、ADX 34.32 在高趋势强度下指向下行。

零售、控股及其他板块

BİM（BIMAS) 和 Migros (米格罗斯) ( MGROS）零售股 60 日回报分别为 -2.6% 和 -32.0%，反映板块疲弱。Migros (米格罗斯)' RSI 24.68、ADX 48.93 与 CCI20 -126.16 显示超卖与强趋势并存。 Koç Holding（科奇控股公司） ( KCHOL）和 Sabancı Holding（公司） ( SAHOL）控股类股票在技术结构中也以"卖出/强烈卖出"信号并因其指数权重而构成压力。在航空行业 THYAO, PGSUS 和 TAVHL 股票完全给出"强烈卖出"信号，RSI 水平处于 28-44 区间、ADX 值运行于 14-46 区间，表明趋势方向向下增强。

3. 技术图形分析

EMA dizilimleri ve Wave Trend uyumu

根据技术扫描数据，BIST 30 股票的绝大多数中，短期、中期和长期 EMA 排列处于"卖出"或"持有"位置。只有 Tüpraş（公司） ( 长期=买入）以及 Aselsan（公司） ( 像 WT=买入）这样的稀有例外给出正向信号。Wave Trend 振荡指标对多数股票给出"底部买入"信号（BIMAS, KCHOL, TOASO, ENKAI, FROTO, MGROS, ASTOR, SISE), 须记住：该信号不是改变方向的"买入"信号，而是表明在现有下跌趋势中已进入超卖区域的警示。真正的趋势反转"买入"信号（Wave Trend 向上交叉）仅有 Tüpraş（公司） 和 Aselsan（公司）' 可以观察到。

回归通道位置与 Pearson 相关性

回归通道内的百分比位置（通道 %）显示价格处于趋势通道的何处。 Tüpraş（公司） 21%, Aselsan（公司） 40%, Ford Otosan（公司） 43%, Sabancı Holding（公司） 45%, Astor Enerji (阿斯托尔能源) % 67 这类高位表明价格接近或高于通道上轨（Astor (阿斯托尔)）；Vakıfbank（银行） %-6, Kardemir (卡尔德米尔) %-8, TR Anadolu Metal (TR安纳多卢金属) %-10, Gübre Fabrikaları (居布雷·法布里卡拉勒) %-10, Ereğli Demir Çelik (埃雷利钢铁) %-16, 土耳其航空公司 %-1, Emlak Konut（埃姆拉克·科努特） GYO 1%，土耳其电信 % 3 这类低位/负位表明价格在下轨或贴近下轨。Pearson 相关系数（r）衡量价格与回归趋势之间的关系。大多数股票呈负相关（r < 0）（Enka (恩卡) -0.64，Ford Otosan（公司） -0.79, Migros (米格罗斯) - 0.91, Astor (阿斯托尔) -0.94），仅Tüpraş（公司） ( r=0.31），Vakıfbank（银行） ( r=0.33），Yapı Kredi（银行） ( r=0.19），İş Bankası（伊什·班卡瑟） ( r=0.17）展现正相关。这情形标示：银行股的价格运动与趋势更为一致（仍然向下），而其他股票的价格偏离趋势、呈现更波动的结构。

分化股票：Tüpraş（图普拉什）和Aselsan

Tüpraş（公司）, 60 日 27.70% 回报、长期 EMA“买入”、Wave Trend“买入”、通道 21%（中轨上方）、正 Pearson（0.31）和“中性”总体评分，它成为指数中技术结构最强的股票。Aselsan（公司） 5.23 亿欧元的合同消息提供基本面支撑，而 Wave Trend"买入"信号和通道 40% 位置标示技术反应潜力。但两只股票在 TradingView 振荡指标摘要中均获得"卖出"建议（TUPRS 买入=7/卖出=12，ASELS 买入=3/卖出=16），这表明短期动量仍偏向卖方。

根据 TradingView 振荡指标数据，BIST 30 股票的 RSI 值在宽幅区间（23.15 - 46.50）内运行，Migros (米格罗斯) (24.68), Gübre Fabrikaları (居布雷·法布里卡拉勒) (23.15), Sasa Polyester (萨萨·波利埃斯特) ( 26.19), Türk Altın (图尔克阿尔滕) (27.25), Pegasus（佩加苏斯） (28.29), THYAO (30.08), Tofaş（公司） (30.94), Ereğli Demir Çelik (埃雷利钢铁) (30.82), Turkcell（公司） ( 30.72）股票跌破 30% 并进入经典超卖区。这些股票的 stochastic %K 数值在 3%，Gübre Fabrikaları (居布雷·法布里卡拉勒) ( GUBRF）与 18%，Anadolu Efes（公司） ( AEFES）在这些水平出现最低点。这些水平增加了技术反弹（bounce）的可能性，但 ADX 数值（GUBRF 51.54, MGROS 48.93, THYAO 46.88, PGSUS 44.59, TRALT 42.66）25% 以上的较高水平表明当前下降趋势强劲，超卖可能持续较久。

MACD与CCI：动能负面与波动率

MACD 柱状图在所有股票中均处于负值区域，最深负值 Migros (米格罗斯) (-25.96), Astor Enerji (阿斯托尔能源) (-25.64), Gübre Fabrikaları (居布雷·法布里卡拉勒) (-37.74), Aselsan（公司） (-8.87), Tüpraş（公司） (-7.77), TR Anadolu Metal (TR安纳多卢金属) (-7.81), THYAO (- 9.19）股票中可见。CCI20 (Commodity Channel Index) 指标（-50（Yapı Kredi（银行）) 以 -233.38（Ereğli Demir Çelik (埃雷利钢铁)) 它在此区间内取值。 Kardemir (卡尔德米尔) (-206.33), Emlak Konut（埃姆拉克·科努特） GYO（-171.75）、Turkcell（公司） (- 177.32), Türk Altın (图尔克阿尔滕) (-170.47), Petkim (佩特基姆) (-161.20), Anadolu Efes（公司） (-164.13), Gübre Fabrikaları (居布雷·法布里卡拉勒) (-182.46), Vakıfbank（银行） (- 188.99）CCI 低于 -150 的股票远离均值；从这些水平反弹可能剧烈，但提醒趋势变化需要成交量和基本面确认。

ADX趋势强度分析

平均趋向指数（ADX）数值对于判断市场处于趋势行情还是横盘至关重要。银行股的 ADX 相对较低（YKBNK 17.87, TAVHL 14.78, VAKBN 22.54, GARAN 20.85）运行时，在工业和消费股（GUBRF 51.54, MGROS 48.93, THYAO 46.88, PGSUS 44.59, TRALT 42.66, ENKAI 41.62, FROTO 39.34, SASA 36.75, KCHOL 36.44, SISE 36.51, SAHOL 36.50, ASELS 34.32, TUPRS 33.69, TOASO 35.06）25%-30 及以上数值表明趋势强劲。高 ADX + 负 MACD + 低 RSI 组合支持“强下降趋势”情景。

5. 风险地图与情景

基本情景：选择性反弹下的横盘/下行延续

考虑到当前技术结构、宏观数据（实际利率为负、通胀29.73%、政策利率36%）及全球风险感知（DXY 102，VIX 18.4），BIST 30指数在13.850-14.100区间横盘，基础情景为个别股票出现技术性反弹（超卖反弹）的选择性走势。指数每日0.17%-0.27%的涨幅受限于银行股的沉重抛压。USD/TRY在49.71附近的相对平稳走势显示外资抛售强度减弱，但买盘意愿尚未恢复。

乐观情景：银行股支持的技术反转

若 XU030 指数放量守住 13,950 水平（今日开盘/收盘区域）并突破 14,050-14,100 阻力，银行股的超卖（RSI 33-46、CCI -50 至 -190）可能触发技术性恢复。 Tüpraş（公司）' 长期 EMA"买入"信号和 Wave Trend"买入"确认表明：当油价下跌停止（Brent 110 USD 上方）时，该股可能把指数向上拉。 Aselsan（公司）' 若伴随国防支出增加的预期吸引外资买盘，可能以行业龙头效应对指数作出正向贡献。该情景下 XU030 可测试 14,250-14,500 目标。

悲观情景：全球风险规避与结构性恶化

若美国 10 年期债券收益率收于 4.85% 上方、DXY 升破 103 或 Brent 跌破 105 美元，抛售压力将渗入新兴市场。BIST 30 的关键支撑为 13,850（前收 13,948 下方）和 13,700（心理/技术）。跌破这些水平可能引发银行股的新一轮抛售（目标：VAKBN 28.50; AKBNK 61.00; GARAN 120.00 区间）和工业股（EREGL 29.00; KRDMD 34.00; SASA 1.40）可能启动价格发现过程。组合相对指数落后 %-15.18，表明相对于市场而言是弱势的 stock picking / timing 策略；在风险管理中应缩小仓位并提高现金比例。
