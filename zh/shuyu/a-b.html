术语与定义

经济、金融和股市术语词典的A–B 组。 定义汇编自 TCMB、竞争管理机构和经济学词典等官方来源。 其他字母组：

A–B C–D E–F 日内 J–M N–P R–S T–Z

A

滥用市场支配地位

在市场上具有重要市场力量的企业，可能比竞争对手更容易影响市场竞争条件。根据竞争委员会法第6条，拥有市场支配地位的企业滥用这种力量限制市场竞争是被禁止的。在第6条评估中，重要的是市场支配地位本身并不违法。一个企业的市场力量可能来自技术优势、效率或优质产品/服

公平收入分配公平收入分配

这是指在一国生产与消费中享有平等机会并获得应得份额。

公平保险保单定价合理的保险单

这是对保险费的确定，使其等于相关保险单的预期价值。

管制价格

这是由企业或公共主管部门确定的价格，不随供求条件的短期波动而变化。一些经济学家将这种价格刚性归因于市场势力。

道德风险道德风险

这是指当他人承担不利结果的成本时，经济单位会做出更冒险选择的现象。

信用证信用证

在满足特定条件的情况下支付出口商品货款的一种担保形式。信用证交易由银行或其他金融机构进行。在这方面，信用证是金融机构为在特定时间内，为特定金额和第三方利益，在其所在国家的一家代理银行开立信贷而发出的一种担保函。

主动求职积极求职

; 向就业机构或直接向雇主申请，通过互联网或报纸等寻找工作，参加口头或书面考试或面试，为创业做准备等活动。

理性预期假说理性预期假说

它是关于经济主体在预测未来时会考虑过去和未来全部信息的观点。

流动性流动性

这是衡量一项金融资产转换为等值现金的难易程度和速度的概念性指标。

算法合谋

Algorithm, a set of steps designed to achieve a goal. In computer science, it is defined as the method by which software performs a task. Algorithms can be used as a tool for pricing by enterprises, for example in online shopping. An enterprise can track the product prices of a competing enterprise through algorithms and set its own product prices accordingly. At a more advanced level, algorithms cease to be a competitive tool

共同成本分配

将生产多种产品的企业的共同成本分配到各产品的生产成本中。企业在分配共同成本时，可以考虑这些产品的需求弹性或产品所在市场的竞争限制。例如，在需求弹性大的竞争性市场中，企业可能不会将共同成本计入其产品/活动中，并且在该市场中降低其价格

采购代表团

为增加出口，在贸易部协调下，由出口商协会和/或组织机构合作，为购买商品或服务而带到该国的机构代表、媒体成员、生产商和进口商组成的代表团。分包商是根据合同为承包商执行部分工作的人或公司。

看涨期权看涨期权

它赋予期权持有人在合同约定价格上购买标的商品、价值或金融指标的权利，且在合同到期时不产生任何义务。

示例：卖出的（开立的）看涨期权被视为负债。( 已签出的看涨期权被视为负债）。

英文定义：赋予购买某一资产权利的合同。

买入买入价

这是指市场参与者愿意买入市场交易资产（如外汇和证券）时支付的价格。

买卖价差买卖价差

它表示任何交易标的双向买卖价格之间的差额。

示例：狭窄的买卖价差表明市场具有流动性。( 买卖价差较窄表明市场具有流动性）。

英文定义：最佳买入价和最佳卖出价之间的差额。

目的无关性目标独立性

这是中央银行自行确定其货币政策目标。

附加宽恕政策

根据附加宽恕规则，在对某一市场的调查中无法从宽恕计划中获益的当事人，若就另一市场的卡特尔提出申请，则既可就第二个市场的卡特尔获得豁免，又可获得对其因第一个市场卡特尔所受处罚的减免。在土耳其竞争法中，相关规定载于《罚款条例》第7条第2款。

主要政策利率最优惠利率

这是构成银行所要求贷款利率基础的比率。

分析资产负债表/TCMB 分析资产负债表分析性资产负债表/CBRT分析性资产负债表

分析性资产负债表是将资产方和负债方各科目相互轧差并按适当类别归并后的资产负债表。土耳其央行分析性资产负债表在归并央行资产负债表科目时，考虑与货币政策有效运作相关的科目，不包含明细。按照货币政策的运作逻辑，资产方列示“国外资产”、“国内资产”和“估值账户”，负债方则列示“外币负债总额”和“央行货币”。对于土耳其央行分析性资产负债表

反竞争协议

这是指企业之间限制相互竞争的秘密或公开协议。此类协议可以是横向或纵向的。

中期目标中间目标

这是指能够直接影响货币政策主要目标、且相较于主要目标更加明确和可衡量的目标。

中间产品中间产品

这是指在生产过程中被消耗掉或成为最终产品组成部分的产品。

券商

中间收益交易套息交易

它是以利率较低（成本更低）的货币借入资金、并把借入资金投资于利率较高（收益率更高）的货币。在信用风险保持不变的假设下，套息交易的净收益由汇率走势决定。

区间内波动区间内浮动

这是名义汇率允许在中央银行确定的核心汇率周围一定区间内波动的汇率制度。

工具独立性工具独立性

这是中央银行自行确定其为实现目标将使用的政策工具。

套利套利

指同时从一市场买入任何证券、外汇或商品，并在另一市场卖出（通过资产互换）以获利的行为。套利交易导致市场间价差缩小。随着通信技术的发展和信息获取成本的降低，市场间价差极低，由此产生的差异会通过此类交易即时消除。

价格递增拍卖增价拍卖

或英式拍卖，一种参与者提交公开报价、价格从低位逐步上调直至确定中标者的拍卖类型。

成本递增行业成本递增行业

这是指随着市场扩大，企业平均总成本随之上升的产业。

累进税累进税制

这是一种随着应税金额增加而税率随之提高的税收制度。

供给供给

供给弹性供给弹性

供给曲线供给曲线

供给过剩超额供给

供给表供给表

供给冲击供给冲击

供给的价格弹性供给价格弹性

或供给弹性，简称 ε，一种基本弹性类型，显示某商品价格上涨百分之一时其供给量变动的百分比。

生计免税额最低生活补贴

最低工资最低工资

委托-代理问题委托代理问题

经营者协会

企业联盟可以根据其成立目标，通过建议性决定指导其成员。这些建议可能涉及销售价格等事宜，并可能有限制竞争的目的和/或影响。必须确定企业联盟的建议是否直接导致企业联盟的约束性决定。事实上，约束性企业联盟决定会限制竞争

有保障的销售基础

企业由于品牌形象、产品/服务质量、可及性、售后服务质量等因素，在不感受到竞争对手竞争压力的情况下实现的销售额被称为核心销售。企业拥有核心销售意味着市场总需求的一定部分（缺乏弹性的）依赖于该企业。通常认为，拥有市场力量的企业拥有核心销售

废弃物处置

这是固体、液体和气体废物的定期和持续储存、通过焚烧予以消除以及转化为产品和能源以回收利用的过程。Avan 项目是在实施项目之前编制的草案项目，用于勾勒主项目的思路。

争夺同一资源的商品争夺同一资源的商品

熊市熊市

指价格下跌的市场。

价格递减拍卖降价拍卖

或荷兰式拍卖（Dutch auction），一种参与者提交公开报价、价格从高位逐步下调直至出现买方的拍卖类型。

收益递减规律报酬递减规律

这是基本经济学概念，指至少一个生产要素固定时，另一可变要素的增加对产量的贡献将逐渐递减。

成本递减行业成本递减行业

公开市场操作公开市场操作

或简称 API（OMO），指中央银行为货币政策目的向金融机构买入或卖出证券。

公开市场操作 - 公开市场操作公开市场操作 - OMO

在土耳其共和国中央银行货币政策目标的框架内，为有效调节货币供应量和经济流动性，以土耳其里拉为计价单位进行的证券即期买卖、有回购承诺的销售（回购）、有再售承诺的购买（逆回购）以及土耳其里拉存入和提取操作。中央银行通过公开市场操作，确保短期利率围绕政策利率形成，并调节金融市场的流动性。

网络效应网络效应

极端财富过度财富
