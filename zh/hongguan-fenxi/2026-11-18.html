1. 全球宏观经济前景

美国：韧性增长，粘性通胀

美国经济在2026年第三季度环比增长3.4%，明显超出1.5%的市场预期；年增长率为2.1%。这一图景表明，在货币政策仍具限制性的环境下，需求并未轻易降温。劳动力市场也印证了这一韧性：失业率为4.1%，非农就业变动为16.5万人，远超预期。然而通胀方面的改善缓慢：年度CPI为3.7%，核心PCE为3.1%，PCE平减指数为3.6%。生产者价格年率升至5.5%，表明成本压力尚未被打破。

欧元区：工业疲弱，PPI高企

欧元区的情况更为脆弱。季度增长为0.4%，表现温和；年度增长为1.3%。工业产出按年下降1.5%，零售销售按月下滑0.7%。最引人注目的数据是生产者价格指数（ÜFE）同比跃升至11.1%：能源驱动的成本压力重新成为议题。尽管如此，整体通胀为4.0%，核心通胀为2.5%。欧洲央行（ECB）政策利率为2.65%，导致实际利率维持在约-1.30个百分点的负值区间；也就是说，货币政策依然宽松。失业率为6.5%，消费者信心为-17.9点，处于历史低位。

全球流动性与风险偏好

美国政策利率为4.0%，实际利率仅为+0.29个百分点；这意味着Fed接近"中性"区间，但由于通胀黏性，激进宽松的空间正在收窄。Fed的利率预测第一年为3.6%，第二年为3.4%——也就是说，市场正在定价一条渐进但有限的降息路径。全球流动性状况因美国的强劲增长和高长期收益率而呈现"充裕但昂贵"的特征。

2. 土耳其宏观经济前景

通胀：去通胀放缓的阶段

土耳其2026年10月年度CPI为29.77%，略高于此前的29.73%；月通胀为2.58%，高于2.4%的预期。核心通胀为28.3%，低于总体水平，但下降速度已经消失（此前为28.7%）。PPI年率为27.41%，月率为1.65%——成本压力几乎已与总体通胀持平。这一图景表明，我们正处于去通胀进程被称为"最后一公里"的最艰难且进展缓慢的阶段。年度通胀在30%区间固化，增加了惯性风险。

货币政策与实际利率

TCMB政策利率在2026年10月从37%下调至36%。这意味着实际利率为+4.80个百分点（约+6.23个百分点），明显保持正值。正实际利率是去通胀所必需的，但会对增长造成压力。降息周期的延续取决于通胀放缓的速度；月通胀维持在2.5%以上将收窄降息空间。

增长与劳动力

第二季度增长环比为1.1%，年率为2.3%，低于预期（2.9%）。工业生产月率为2.1%，虽释放复苏信号，但年率2.61%有限。失业率为8.5%，参与率为52.7%。产能利用率为74.5%，较为温和；商业信心降至99.8，消费者信心则从91.9急剧下降至84.8，表明内需正在走弱。

3. 内需、信贷和流动性

利率-信贷渠道

尽管政策利率降至36%，存款利率仍高达42.04%；消费贷款利率为66.46%，高于此前的64.74%。这一分化至关重要：政策利率下降而信贷成本上升，表明传导机制并未完全发挥作用，风险溢价和融资成本正在传导至家庭贷款。信贷增长年率为35.29%，虽高但正在放缓（此前为36.32%）；M3货币供应增长降至26.87%。

内需走弱

零售销售月率仅为0.1%，年率为7.7%（此前为10.1%）。结合消费者信心的急剧下降，这些数据证实高信贷利率正在冷却内需。机制如下：高名义利率 → 贷款分期负担增加 → 耐用品消费推迟 → 零售和汽车等对利率敏感行业的销售萎缩。这对去通胀是理想的，但对公司营业额而言是不利的发展。

4. 全球风险偏好和利率预期

市场波动性与美元

VIX指数从22.91跃升至25.46，涨幅11.13%，表明风险偏好恶化。DXY为103.56，持平；可以说美元在全球范围内保持强势但稳定。美国国债曲线引人注目：3个月期4.14%，5年期4.90%，30年期5.46%。长期收益率明显高于短期，表明"期限溢价"已经回归，市场正在定价长期通胀/成本风险。

对BIST的反映

VIX的跃升和美国高长期收益率，将对新兴市场的资本流入起到限制作用。事实上，BIST 100日内下跌1.53%；以美元计损失为1.72%。风险偏好的恶化，为外国投资者在土耳其等高贝塔市场减少头寸提供了基础。

5. 预算和外部平衡

预算赤字与经常账户平衡

中央政府预算在2026年10月录得4810亿里拉赤字（前值为5320亿里拉）。赤字居高不下，暗示财政政策并未支持去通胀进程，反而在提振内需方向上发挥作用。尽管如此，经常账户在2026年9月录得27.2亿美元顺差（前值为40.5亿美元顺差）——得益于能源价格和旅游收入，外部平衡处于有利状态。

对外贸易与储备

10月出口259亿美元，进口325.8亿美元；贸易逆差扩大至67亿美元（前值为52.3亿美元）。第三季度旅游收入255.3亿美元，表现强劲；游客数量同比增长0.4%。外汇储备570.2亿美元，温和增长。实际有效汇率指数升至107.76，表明里拉实际升值——这是侵蚀出口竞争力的一个因素。

6. 能源、大宗商品、外汇和债券市场

石油与黄金

布伦特原油93.07美元/桶，WTI 85.61美元/桶，维持高位。这一能源价格水平对土耳其这样的能源净进口国而言，是经常账户平衡和通胀的压力因素。黄金每盎司3851.90美元，每克黄金6246.19里拉——黄金既是全球避险需求的载体，也是里拉贬值预期的载体。

汇率与债券

USD/TRY 50.44，EUR/TRY 55.51，里拉面临有限的贬值压力。汇率与通胀的互动至关重要：里拉每贬值1%，都会通过进口投入成本传导至PPI，并随时间传导至CPI。实际有效汇率以107.76保持强劲，表明这一渠道目前作用有限，但存在反转风险。

7. 传导机制：从宏观到市场

利率渠道

政策利率（36%）→ 存款利率（42.04%）→ 贷款利率（66.46%）→ 投资/消费决策 → 公司销售 → 利润率 → 估值。在这一链条中，贷款利率远高于政策利率，表明传导在"紧缩"一侧发挥作用。高企的信贷成本尤其压制银行和零售行业的利润率。

汇率与全球利率渠道

汇率渠道：USD/TRY上升 → 进口投入成本 → PPI → CPI。全球利率渠道：美国30年期国债5.46% → 全球风险溢价 → 外国资本流动 → 对里拉资产的需求 → BIST估值。VIX的跳升证实该渠道目前正朝"避险"方向发挥作用。

8. 对BIST 30的影响：行业渠道

银行与工业

高存款利率对银行而言是融资成本，但对净息差而言产生双向影响；信贷增长放缓限制盈利能力。对工业企业而言，高利率提高投资成本，里拉实际升值压制出口利润率。控股公司则通过投资组合多元化得到部分平衡。

零售与防御性行业

零售销售放缓限制了零售行业的营收增长；消费者信心下降加深了这一压力。与此同时，能源价格高企对能源密集型工业部门造成成本压力，而拥有防御性现金流的公司在高利率环境中可能保持相对韧性。

9. 情景和监测框架

基准情景（50%）：渐进式去通胀

月度通胀回落至2%-2.5%区间，土耳其央行（TCMB）继续有限降息，增长维持在2%-3%区间。在这一情景下，伊斯坦布尔证券交易所（BIST）在高利率压力下横盘震荡。

乐观情景（25%）：快速去通胀

核心通胀显著回落，风险溢价下降，外国资本流入加速。将使这一情景失效的发展是：月度通胀重新升至3%以上。

悲观情景（25%）：惯性与汇率压力

能源价格上涨，里拉贬值加速，通胀惯性增强。需监测的指标：月度CPI、PPI-CPI剪刀差、VIX、USD/TRY、储备、贷款利率-存款利率剪刀差。

10. 结论与评估

土耳其经济正处于一个由正实际利率（4%.80）支撑、但存在惯性风险的通缩进程的艰难阶段。在全球方面，美国强劲的增长和高企的长期收益率限制了资本流向新兴市场；VIX的跳升证实风险偏好已经恶化。在国内方面，贷款利率远高于政策利率，表明传导在紧缩一侧发挥作用，内需正在降温。高企的预算赤字削弱了财政政策对通缩的支持。未来一段时期，月度通胀路径、汇率稳定和全球风险偏好将对BIST 30的走势起决定性作用。本评估仅供教育和分析之用；不构成投资建议。

方法论与术语

  • 信号（总体）： 基于个股的总体技术评估（强力买入 / 买入 / 中性 / 卖出 / 强力卖出）；在面板和技术扫描表中可见。
  • 振荡器投票： RSI、StochK、MACD、CCI、WT 等指标的个别买入/卖出票数；以"11 买入/8 卖出"形式给出，并可能与整体信号相矛盾（例如面板信号为卖出时，振荡器票数中某只个股可能出现正向背离）。
  • WT（波浪趋势）： 短期周期（顶/底）振荡器；产生买入/卖出票数。
  • 通道（%N）： 价格在 60 日回归通道中的位置；0% 接近通道下沿（底部区域），100% 接近通道上沿（顶部区域）。
  • ADX: 平均方向指数（ADX）；数值高于 25 显示强趋势，低于 20 显示弱/横盘走势。
  • r: 在 60 日窗口中计算的皮尔逊相关系数（趋势强度指标）；在模型投资组合表中以括号形式给出。
  • 现金： 模型组合中未配置于股票、出于谨慎目的而持有的比例。
